# SIMBA Calculator — نسخه 3.0

این نسخه با توجه به ایرادهای نسخه قبلی بازنویسی شده است.

## تغییرات اصلی
- چیدمان ۶ ستونه حفظ شده است.
- کلید `000` حذف شده و `.` جای آن قرار گرفته است.
- `AUTO REPLAY` کاملاً حذف شده است.
- `CORRECT` به‌جای آن عریض شده و مانند Backspace عمل می‌کند.
- جای `+` و `−` نسبت به نسخه قبلی عوض شده است.
- صدای کلیدها با صدای داخلی Key Click اندروید پیاده‌سازی شده و کلید SOUND آن را روشن/خاموش می‌کند.
- مشکل قبلی `TONE_PROP_CLICK` وجود ندارد.
- محتوا با System Barهای گوشی هماهنگ شده تا Status Bar روی اپ نیفتد.
- عددهای کلیدها و عدد نمایشگر بزرگ‌تر شده‌اند.
- تاریخچه تا ۵۰ محاسبه ذخیره می‌شود و مراحل محاسبه زنجیره‌ای را نگه می‌دارد.
- CHECK چپ/راست برای مرور مراحل تاریخچه پیاده‌سازی شده است.
- محاسبات زنجیره‌ای به سبک ماشین‌حساب حسابداری هستند؛ مثلاً `2 + 3 × 4 = 20`.
- درصد حسابداری برای جمع/تفریق و درصد معمول برای ضرب/تقسیم پیاده‌سازی شده است.
- Memory با MRC / M+ / M− با دقت BigDecimal ذخیره می‌شود.
- CE فقط ورودی فعلی را پاک می‌کند و AC وضعیت محاسبه را پاک می‌کند.
- ممیز در هر عدد فقط یک بار پذیرفته می‌شود.

## GitHub Actions
این پروژه عمداً از `android-actions/setup-android` و `gradle/actions/setup-gradle` استفاده نمی‌کند؛ SDK و Gradle به‌صورت دستی نصب می‌شوند تا مشکلات نسخه قبلی تکرار نشوند.

Workflow از Gradle 9.5.1 و Android SDK 35 استفاده می‌کند.

### نکته آپلود در GitHub
اگر `.github` در فایل‌منیجر ویندوز نمایش داده نمی‌شود، داخل GitHub این فایل را بساز:

`.github/workflows/build-apk.yml`

محتویات ZIP را در ریشه Repository قرار بده؛ خود پوشه `DesktopCalculator_Final` را یک سطح بالاتر آپلود نکن.
